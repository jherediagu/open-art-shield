**OpenArtShield does not make images AI-proof.** It applies real protection layers,
runs them through the transforms and removal attacks that actually happen to images
online, and reports how much survived. Every claim on this site is reproducible from
the repository.

<CardGrid>
  <Card title="Trace" icon="magnifier">

    later.
  </Card>
  <Card title="Declare" icon="document">

## Install

```bash
npm install -g @openartshield/cli
oas protect artwork.png --message "artist=jane"
```

The same pipeline is available as a Node SDK (`@openartshield/node`), a pure
browser package (`@openartshield/web`), and a self-hosted REST server
(`@openartshield/server`, one `docker build`). See [Install]({{base}}/install/).

## What survives

From the [continuous benchmark]({{base}}/reference/benchmark/): deterministic inputs,
18 transforms and published attacks, exact payload recovery required.

| Protection  | Natural-like image | Survived |
| ----------- | -----------------: | -------: |
| DCT s=8     |           54.13 dB |     9/18 |
| DCT s=16    |           50.97 dB |    11/18 |
| TrustMark Q |           49.99 dB |    18/18 |

Robustness to common transforms is not resistance to a dedicated adversary.
The [threat model]({{base}}/reference/threat-model/) says exactly what each layer claims
and does not claim.
