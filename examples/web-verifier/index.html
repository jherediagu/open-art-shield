OpenArtShield verifier

Check whether an image carries an OpenArtShield watermark. Everything runs in your browser - the image is never uploaded.

1. Pick an image

2a. Verify a DCT watermark (with its sidecar)

Paste the *.openartshield.json sidecar that oas protect produced next to the image.

2b. Decode a TrustMark watermark

No sidecar needed. The ~47 MB decoder model loads from Adobe's CDN on first use (or pick a local decoder_Q.onnx if your network blocks it) and runs locally via WebGPU/WASM.

A verified mark shows a signal survived - absence of one proves nothing, and a motivated adversary can remove any watermark. See the project's threat model for the honest framing.
